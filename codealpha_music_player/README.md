# 🎵 Music Player

A modern and interactive **Music Player Web App** built using **HTML, CSS, and JavaScript**.
The application allows users to play music, manage their playlist, add new songs, and delete songs from the collection.

---

## ✨ Features

* 🎵 Modern and responsive music player interface
* ▶️ Play and pause music
* ⏮️ Previous and next track controls
* 🔀 Shuffle functionality
* 🔄 Repeat functionality
* 📋 Playlist management
* 🎶 Three default songs included
* ➕ Add new local songs to the playlist
* 🗑️ Delete songs from the playlist
* ❤️ Add songs to favorites
* ⏱️ Music progress bar with duration
* 🔊 Interactive music controls
* 🌙 Modern dark-themed UI
* ⚡ Smooth and user-friendly experience

---

## 🛠️ Technologies Used

| Technology     | Purpose                                                        |
| -------------- | -------------------------------------------------------------- |
| **HTML5**      | Structure of the music player                                  |
| **CSS3**       | Styling, layout, animations, and responsive design             |
| **JavaScript** | Music playback, playlist management, adding and deleting songs |

## 📸 Preview

The music player features a **modern dark-themed interface** with a purple accent color, playlist management section, music controls, and a clean now-playing area.

---

## 🎶 Default Playlist

The player comes with three songs by default:

* 🎵 **Midnight Drive** — Luna Waves
* 🎵 **Neon Dreams** — The Night Riders
* 🎵 **Afterglow** — Echo Avenue

Users can also add their own local music files and remove songs from the playlist whenever they want.
