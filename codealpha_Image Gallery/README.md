# 🖼️ Interactive Image Gallery

A modern and interactive **Image Gallery Web App** built using **HTML, CSS, and JavaScript**.
The project allows users to browse images, filter them by category, and interact with images and buttons through smooth hover effects and animations.

---

## ✨ Features

* 🖼️ Interactive image gallery
* 🔍 View images in a clean and organized layout
* 🗂️ Filter images by category
* 🌿 Nature category
* 🚗 Cars category
* 🐾 Animals category
* 💻 Technology category
* 🖱️ Smooth hover effects on images
* ✨ Interactive hover effects on buttons
* 📱 Responsive and user-friendly design
* 🎨 Modern dark-themed interface
* ⚡ Smooth and interactive user experience

---

## 🛠️ Technologies Used

| Technology     | Purpose                                                   |
| -------------- | --------------------------------------------------------- |
| **HTML5**      | Structure and content of the image gallery                |
| **CSS3**       | Styling, responsive layout, hover effects, and animations |
| **JavaScript** | Category filtering and interactive functionality          |

## 📸 Preview

The gallery features a modern dark-themed design with categorized images, interactive filter buttons, smooth hover effects, and a clean responsive layout.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Interactive-Image-Gallery.git
```

### 2. Open the Project

Navigate to the downloaded **Interactive-Image-Gallery** folder.

### 3. Run the Gallery

Open `index.html` in your preferred web browser.

🎉 **Your interactive image gallery is ready to explore!**
