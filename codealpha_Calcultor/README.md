🧮 Calculator

A simple and modern Calculator Web App built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations with a clean, responsive, and user-friendly interface.

✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage calculation
* 🗑️ Delete button
* 🔄 Clear/Reset button
* 🔢 Decimal number support
* 📱 Responsive and clean UI
* ⚡ Fast and interactive calculations

🛠️ Technologies Used

* HTML5 — Structure of the calculator
* CSS3 — Styling, layout, colors, and responsive design
* JavaScript — Calculator logic and functionality

📸 Preview

The calculator features a modern dark-themed interface with orange operator buttons and a simple, easy-to-use layout.
